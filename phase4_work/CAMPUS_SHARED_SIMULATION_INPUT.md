# 校园统一推荐与小时仿真输入

2026-09-17。

湖北经济学院推荐和小时仿真不再依赖缺失的旧 LoadTimeseries 表。统一入口 app/services/campus_simulation_input.py，复用现有校园规则和16栋已绑定建筑，整年生成小时输入，非闰年8760小时、闰年8784小时。无数据库结构变更，无历史数据覆盖。

大屏和碳核算为当年截至快照时间，推荐及整年小时仿真为所选年度完整运行窗口；窗口不同，不能直接比较两者累计值。对相同完整小时，基准购电、碳排和SOC逐项一致。

既有光伏出力、充电桩负荷和天然气直接排放作为基础输入，既有储能采用既定容量、效率和峰谷时段重新连续调度。新增PV叠加出力；新增储能容量/功率加到既有容量，使用新方案调度策略。天然气纳入总碳排；空调、照明仍包含在建筑负荷，节能模型是既有静态比例模型。

请求兼容增加可选site_id。多园区单位未明确site_id时拒绝计算；所选园区必须属于请求单位，场景已有园区标识时必须一致。推荐结果和生成场景保存园区及输入来源。旧单位级调用在只有一个园区或没有园区时保持兼容。

接口增加 GET /api/result-interface/campuses/{site_id}/simulation-baseline?year=...，返回同一输入的负荷和气象统计。推荐及小时仿真页面使用此接口显示校园完整年度输入状态。批量仿真传递site_id。推荐失败使用页面单一错误区，取消HTTP层重复弹窗。

所有校园能源输入为示范仿真数据。电价、投资等是功能仿真假设，非学校结算或真实工程报价。未绑定风机不生成既有风机；候选新建风电仍为模型假设。

校园基准冻结为包含整年小时输入、既有设备配置、模型版本、因子和价格来源的快照，并使用 SHA-256 校验。推荐转场景保留快照；小时重放、年度推演、长期推演和新报告复用快照，不覆盖历史运行。报告拒绝混用不同基准的推荐、批次和旧核算批次。

年度和长期推演以无新增措施快照为基准，首年调用小时能源平衡，避免对已实施措施重复计入；后续年度按负荷、措施计划和因子演化。既有储能年度购电损耗保留，储能不计作发电设备。

限制：校园整年小时仿真须从年初开始，避免把截断储能初始状态冒充连续结果。后续年份是年度近似，不是逐小时调度，新增储能和消纳效果需要小时复核；报告已有历史快照不会自动替换为新的运行结果。真实外部指标替换仍须人工确认映射。校验码用于完整性检查，不代表数据库管理员无法修改数据。

测试：全量后端94通过、3跳过；前端类型检查/生产构建通过（现有包体积警告）；大屏到建筑核算、三维建筑、跨镜叠加3项Playwright通过。新增整年16栋基准逐小时购电、碳排、SOC一致性，以及推荐和小时业务服务基准一致性测试通过。
