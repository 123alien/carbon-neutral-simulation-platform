# 中国绿证公开数据验证报告

- 来源：国家能源局《中国绿色电力证书发展报告（2024）》及《中国绿色电力证书发展报告（2025）》。
- 数据类别：`REAL_PUBLIC_OFFICIAL`；为全国汇总，不是企业合同或持仓。
- 原始粒度：年度。
- 2024：全国核发 47.34 亿个，全年交易 4.46 亿个；绿证单独交易全年均价约 5.59 元/个。
- 2025：全国核发 29.47 亿个，全年交易 9.30 亿个；2025 电量生产年绿证均价 5.57 元/个。

平台分别保存核发量、交易量及价格，不把绿证与绿电合同混为一谈，也没有虚构企业绿证合同。2025 价格字段的生产年份口径已写入来源字符串。
