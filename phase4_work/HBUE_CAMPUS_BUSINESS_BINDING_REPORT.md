# 湖北经济学院智慧低碳校园业务绑定报告

## 绑定范围

本场景仅绑定16栋已具名且具有真实 OSM 建筑轮廓的核心建筑。其余109栋建筑继续显示真实轮廓，但不生成能耗、用水或碳排放业务指标。全部业务指标均标记为“示范仿真数据”。

图书馆、教学楼4和学生事务中心因真实建筑轮廓身份尚未确认，未进入业务绑定。

## 业务分类与能源系统

| 业务类型 | 建筑 | 主要系统 |
| --- | --- | --- |
| 教学 | 教学楼一、二、三，知行楼、群贤楼 | 电、水、空调、照明 |
| 实验教学 | 实验楼一、实验楼二 | 电、水、空调、照明、实验过程负荷 |
| 行政及办公 | 行政楼、法商学院综合楼、香帅楼 | 电、水、空调、照明；香帅楼配置屋顶光伏 |
| 学生住宿 | 枫苑宿舍 | 电、水、空调、照明 |
| 餐饮服务 | 三清园 | 电、水、天然气、空调、照明 |
| 公共服务 | 大学生活动中心、室内体育馆、校医院、人文艺术楼 | 电、水、空调、照明；活动中心配置储能，体育馆停车区配置充电桩 |

平台建立8类校园能源系统、68个设备和68个计量点。设备、计量点与建筑均通过相同的 `building_id` 关联。

## 数据生成规则

- 教学建筑按工作日课程时段形成8—12时、14—18时峰值，周末显著下降。
- 实验楼在8—21时叠加实验设备过程负荷。
- 行政办公建筑仅在工作日8—18时维持高占用率。
- 宿舍在早间、晚间和夜间形成用电、用水峰值。
- 食堂按早、中、晚三餐形成用电、用水和天然气峰值。
- 体育馆在16—22时负荷较高；校医院保留夜间基础负荷。
- 空调负荷与逐时温度、占用率共同变化；照明与占用时段和昼夜关联。
- 香帅楼光伏按昼夜和辐照变化；充电桩按到校、离校时段变化；储能 SOC 为连续周期曲线。

数据库已写入连续7天、168小时逐时数据，共8736条时序事实；年度结果按照同一规则完整计算8760小时后写入建筑参数快照，不使用7天样本直接冒充全年值。

## 建筑级年度结果

| 指标 | 结果 |
| --- | ---: |
| 年度综合用电量 | 15,920,511.65 千瓦时 |
| 年度用水量 | 142,230.39 立方米 |
| 年度天然气量 | 301,802.99 立方米 |
| 年度碳排放量 | 9,731.97 吨二氧化碳当量 |

建筑级排放采用示范因子计算：电力0.5703千克二氧化碳当量/千瓦时，天然气2.162千克二氧化碳当量/立方米。上述因子与能源参数属于示范仿真假设，不代表湖北经济学院实际结算数据或正式碳盘查结果。

## GIS 展示规则

- GIS 绘制125栋真实建筑轮廓。
- 只有16栋已绑定核心建筑显示能耗和碳排热力。
- 未绑定建筑只显示轮廓，并提示“尚未绑定能碳业务对象”。
- 建筑点击后通过平台建筑对象进入详情，不为无名建筑生成虚构指标。

## 跨镜追踪预留字段

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| `campus_id` | `HBUE` | 校园唯一编码 |
| `building_id` | `HBUE-B001` | 与 GeoJSON 和业务建筑一致 |
| `floor_id` | `HBUE-B001-F01` | 建筑内楼层编码 |
| `area_id` | `HBUE-B001-F01-A01` | 楼层内区域编码 |
| `timestamp` | ISO 8601 UTC | 事件或指标时间 |

当前不保存人员身份、视频或跨镜轨迹；上述字段仅用于未来将经过授权的结构化行为结果关联到校园空间对象。
