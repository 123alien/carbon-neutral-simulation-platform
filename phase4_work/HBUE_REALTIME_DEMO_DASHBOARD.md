# 校园当前时间示范仿真大屏

2026-09-16

原大屏依赖年度仿真任务的小时结果，校园无匹配任务时侧栏为空。新增只读后端快照接口，复用校园初始化脚本的教学、实验、行政、宿舍、餐饮等规则，不改变历史观测、场景结果或数据库。

接口：GET /api/result-interface/campuses/{site_id}/live-demo，history_hours 默认168，最多8784。仅允许湖北经济学院已标记示范数据的核心建筑，其他园区拒绝。真实125栋轮廓和16栋业务绑定不变。

时间为服务器当前时间，Asia/Shanghai 带时区输出。前端每15秒请求后端；数据不是前端随机生成。建筑负荷为校园既有逐小时规则，小时内负荷保持该时段水平；累计排放按已完成小时和当前小时已过比例计算，SOC按本小时充放电速率连续计算。

储能按840千瓦时示范容量，SOC范围10%—90%，充放电效率各95%，夜间充电、傍晚放电，逐小时延续SOC且充放电互斥。光伏沿用720千瓦和0.82性能比假设。未绑定风机时风电显示零，不补造风机。

能源平衡：建筑负荷+充电桩=光伏+储能放电+购电-储能充电-弃电。空调、照明已包含在建筑负荷，不重复相加。购电碳排按建筑需求比例分配，天然气排放归于食堂。完整率仍为既有接入数据完整率，不代表真实观测覆盖率。

小时历史为完整小时千瓦时。当前对象沿用大屏既有小时字段兼容格式作为每小时等效速率，仅供显示千瓦；不把当前对象按整小时加入累计能量。当前时段指标仅统计已完成小时；年度累计另包含当前小时已过比例。月度趋势最后一个月为截至当前时间的部分月，不代表完整月预测。

真实数据替换：保持该快照接口和GIS展示层，后续在后端增加经人工确认的设备—建筑—指标映射及真实值选择。暂存未映射设备不会自动替换示范数值，也不冒充学校实测。当前尚未实现自动混合真实值替换。

验证：后端新增2项通过，能源守恒、SOC连续、可复算、园区隔离、建筑碳排汇总一致。Playwright校园实际只读接口大屏、三维近景、跨镜热力叠加3项通过；前端类型检查及构建通过。截图 qa_report/hbue-campus-live-dashboard.png。
