# 湖北经济学院 GIS 能碳热力实现

## 数据边界

- 保留现有真实校园边界和 125 栋 OpenStreetMap 建筑轮廓。
- 仅对 16 栋已绑定 `building_id` 的建筑显示能耗、碳排和热点。
- 未绑定建筑仅显示轮廓，不分配虚构业务指标。

## 热力与热点规则

- 能耗热力：使用建筑 `annual_energy_kwh`，按16栋已绑定建筑内的最大值归一化。
- 碳排热力：使用建筑 `annual_emission_tco2e`，按16栋已绑定建筑内的最大值归一化。
- 高能耗热点：年用电量位于已绑定建筑前25%。
- 高碳排热点：年碳排放位于已绑定建筑前25%。
- 两类热点可同时显示，并用不同颜色标识。

## 轨迹图层预留

地图中已创建空的轨迹 `LayerGroup`，当前不加载数据、不请求跨镜接口、不生成模拟轨迹。空间对齐仅预留：

`campus_id / building_id / floor_id / area_id / timestamp / camera_id`

待得到真实 API 和响应格式后，再定义轨迹对象、导入映射和筛选能力。
