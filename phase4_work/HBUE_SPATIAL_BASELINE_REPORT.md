# 湖北经济学院校园空间基准构建报告

## 数据基准

- 校园：湖北经济学院
- `campus_id`：`HBUE`
- 坐标参考：WGS84（EPSG:4326 / GeoJSON CRS84 坐标顺序）
- 校园边界：OpenStreetMap `way/908384239`
- 建筑轮廓：OpenStreetMap `building=*`，并补充已有明确名称的实验楼一、实验楼二和室内体育馆轮廓
- 许可：OpenStreetMap contributors，ODbL
- 生成方式：`python scripts/build_hbue_spatial_baseline.py`

## 结果

| 检查项 | 结果 |
| --- | ---: |
| 校园内建筑轮廓 | 125 |
| 已有名称建筑 | 103 |
| 无名称建筑 | 22 |
| 优先核对类别已确认 | 15 |
| 优先核对类别待确认 | 3 |
| 跨越校园边界而排除的候选轮廓 | 3 |

所有保留建筑面的全部顶点均位于 OSM 校园边界内。被排除的边界交叉对象为 `way/101809639`、`way/101928812` 和 `way/102244668`。

## 待确认建筑

- 教学楼4
- 图书馆
- 学生事务中心

上述对象在当前 OSM 建筑面中没有找到可可靠对应的名称，因此没有人工猜测位置，也没有将其他无名轮廓强行核名。后续需要校方建筑台账、测绘图或带坐标的官方平面图进行确认。

## 数据使用边界

GeoJSON 中的建筑位置和轮廓来自 OSM，不是校方测绘成果。`verified=true` 表示 OSM 建筑面已有可识别名称，不表示经过校方测绘或产权审核。无名称轮廓统一采用 `unknown_building_<osm_id>`，并设置 `verified=false`。

GIS 页面只对已经与平台建筑对象完成映射的轮廓叠加能耗或碳排热力。未绑定业务对象的真实建筑轮廓只做空间展示，不分配虚构指标。
