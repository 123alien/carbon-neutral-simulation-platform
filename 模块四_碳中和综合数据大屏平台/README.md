# 模块四：碳中和综合数据大屏平台

独立建设的数据汇聚、时空对齐与综合可视化应用。现有 phase4_work 属于模块一，本项目不修改其业务、数据库或算法。

## 职责

- 接入物联网观测、模块一碳核算与仿真结果、模块三跨镜统计结果。
- 统一校园空间编码、数据时间、单位、质量状态及来源追溯。
- 展示综合态势、低碳推演、空间活动三个专题。
- 提供版本化动态指标引擎：自定义排放因子、碳核算/能效公式、试算、发布和历史留痕。
- 独立维护接入配置、空间映射、展示缓存和快照，不合并上游数据库。

## 规划目录

```text
backend/     后端适配、聚合、配置及展示接口
frontend/    独立大屏、GIS、三维及接入配置页面
contracts/   与模块一、模块三、物联网的数据契约
docs/        设计、联调及验收说明
tests/       接口、对齐、隔离及展示验证
```

已搭建独立前后端骨架与真实校园空间展示。启动命令和当前实现边界见 docs/启动与阶段边界.md。业务结果适配与持久化将在后续联调中实现。

现已接入模块一校园示范业务结果和示范跨镜路径，最新进展见 docs/阶段二接入说明.md；接口来源与边界见 contracts/结果接入契约.md。

低碳推演专题已自动读取模块一校园基准、低碳与关联强化运行，详见 docs/低碳推演接入说明.md。计算仍属于模块一，模块四不重新计算排放。

## 数据约束

- 第三方接口由后端调用，凭证不进入前端或版本控制。
- 实测、示范仿真和预测数据明确区分，不静默替换。
- 统一 campus_id、building_id、floor_id、area_id；摄像头额外使用 camera_id。
- 观测时间与接收时间分别记录，未确认的空间映射允许为空。
- 像素轨迹不直接当作经纬度；GIS连线只表达跨区域活动顺序。
- 未获得统计预测区间时，不伪造置信区间。
- 动态指标公式仅允许白名单算术语法和指定函数；发布前必须试算通过，发布采用版本冲突校验和原子写入。

## 推荐技术栈

前端 Vue、ECharts、Leaflet、Three.js；后端 FastAPI、PostgreSQL。独立部署，不与模块一共用服务端口。

边缘平台一键进入已提供独立源的后端认证代理。共享管理员入口必须显式启用，仅适用于受信任局域网；启动、关闭和权限边界见 [边缘平台共享入口](docs/边缘平台共享入口.md)。

跨镜平台也提供独立的共享入口，保留任务参数、后端维护登录 Token，详见 [跨镜平台共享入口](docs/跨镜平台共享入口.md)。
