# 结果接入契约（当前阶段）

模块四仅通过后端 HTTP 读取模块一；不导入其 Python 服务、不读写其数据库。地址由 MODULE_ONE_BASE_URL 指定，默认本机8000。

校园通过 /api/sites 的 code=HBUE 自动发现，不写死数据库主键。校园快照来自 /api/result-interface/campuses/{id}/live-demo 。本年累计指标按上游建筑汇总；校园总碳排直接采用上游总量。当前快照为功率，过去已完成小时为能量，不混算。

建筑通过 building_id 对接真实空间轮廓。未匹配建筑不分配数值。当前接口中的 floor_id / area_id 可为空，后续不确定字段不补造。

长期路径自动读取模块一 long-term/runs 和 scenarios，按园区、冻结基准、source_run_id筛选匹配结果，现已存在校园基准/低碳/强化运行。碳市场继续读取 carbon-market 只读接口。缺少校园结果时不借用其他园区结果。模块一暂未提供区间字段时，模块四基于每条运行记录的负荷增长率、电网因子变化率和基准排放因子执行固定种子的 Monte Carlo 参数不确定性传播，返回95%预测区间、样本量、方法和假设；结果标记为 DEMO_MODEL_INTERVAL，不冒充学校历史误差回测结果。

轨迹通过模块一已有 cross-camera-adapter/paths 后端服务转接，保持原 Global ID、摄像头锚点、时间、分数和像素详情；允许示范／真实数据源选择，禁止静默备用。当前不是模块四直接完成模块三的鉴权联调。

动态指标规则由模块四独立维护，不回写模块一。规则包含指标编码、名称、分类、单位、公式、精度、启用状态和排放因子参数；公式只能引用接口公开的标准变量并使用白名单运算。`/api/metric-rules/preview` 仅试算不落盘，`/api/metric-rules/publish` 在版本一致且全部公式计算成功时原子发布。`/api/metric-rules/rollback` 将选定历史规则内容作为新版本发布，不覆盖既有审计链。大屏结果携带 `metric_rule_version`、公式和计算错误状态，保证可追溯。

物联网本阶段只读取 external-data/status，不触发采集、不控制设备。仅返回白名单状态，不返回登录响应或凭证。气象站服务可达但离线、有效值为0时，不标为校园实测数据在线。

当前刷新30秒，后端缓存25秒，未实现流计算、高并发验收、配置持久化及自定义指标引擎。
