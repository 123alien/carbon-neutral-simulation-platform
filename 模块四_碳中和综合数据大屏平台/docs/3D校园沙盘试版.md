# 3D校园沙盘试版

入口：模块四中心地图工具栏“3D校园沙盘”。GIS和2.5D入口保留，三维组件与渲染依赖仅按需加载。

空间复用现有校园边界、125栋建筑Polygon、道路中心线、湖面与绿地GeoJSON，新增只读景观接口 `/api/spatial/landscape`。不修改模块一文件、数据库、建筑业务绑定及核算结果。

天气默认通过模块四后端获取当前区域天气，自动联动晴/阴/雨及昼夜光照，并显示外部实际返回指标、来源与气象时间。区域模型数据明确区别于校园设备实测；独立手动示意天气选项仍保留。具体见《当前天气联动》。不修改能源与碳排计算。

采用WebGL真实三维透视、旋转/平移/缩放、日光与阴影。16栋业务楼加入窗格、窗台、屋顶收边及示意屋顶构件；根据公共建筑/住宿/常规楼栋采用不同示意高度和材质。其余建筑为低细节空间背景。树木分布在已有绿地区域，排除建筑面，树冠颜色和大小按确定性规则变化；均非实测树木点位。模型并非湖北经济学院建筑实景精细复原，不宣称航拍重建或BIM精度。

楼栋保持自然灰蓝屋顶和浅色立面，热力以建筑位置附近的指标环叠加，不涂满建筑。碳排/能耗读取同一16栋业务结果；高值阈值沿用75百分位。名称点击与三维对象拾取打开同一建筑详情。摄像头路径继续使用同一DEMO/LIVE模型，只投影经纬度节点或明确segments，绝不投影视频像素。

树木、窗格、窗台和屋顶构件使用实例批次，道路按材质合并。像素比上限1.5，阴影图2048，静止时停止渲染；视角、尺寸和业务图层更新触发重绘，组件卸载释放GPU资源。无法使用WebGL时提示切回GIS或2.5D，不静默冒充三维成功。

性能验证仅覆盖测试机器的静止渲染计数，不保证所有机器帧率。此版比2.5D增加环境与楼栋层次，仍与用户参考的精细实景模型有差距。
