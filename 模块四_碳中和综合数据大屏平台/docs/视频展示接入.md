# 真实跨镜任务视频展示

入口：大屏“视频展示”专题 → 选择真实任务 → 打开任务视频。

读取上游已存在任务，不创建任务、不上传视频、不修改算法、数据库或摄像头配置。两路播放器保留上游真实编号 `cam1`、`cam2`；没有学生/教师等虚假身份分类。

## 已核实接口

2026-09-18读取上游OpenAPI，实际提供 `GET /api/v1/tasks/{task_id}/videos/{camera}`。已存在任务 `20260916_220912_3a98c7` 的两路接口分别返回 `cam1_result.mp4`、`cam2_result.mp4`，Content-Type为video/mp4。这是任务结果录像，不是直播。

模块四 `GET /api/videos/tasks/{task_id}/{camera}` 先通过模块一现有后端鉴权任务列表确认任务可访问，再请求固定上游视频路径。上游当前视频路由没有Bearer安全声明，实测无需Token；跨镜任务列表及LIVE结果仍由模块一既有后端Token缓存获取。前端不持有上游账号、密码、Token，不直接访问第三方地址。

当前视频编号仅开放已确认的cam1/cam2；不接受任意URL。上游地址由后端 `CROSS_CAMERA_BASE_URL` 设置，默认当前局域网服务。上游若后续要求视频鉴权，应继续扩展后端代理，而不是向前端传Token。

## 播放与异常

播放器支持浏览器原生播放、暂停、音量和全屏。上游目前忽略Range，代理根据Content-Length返回206与Content-Range，支持定位；每次定位可能需要重新读取并跳过上游前段，因此长视频优化需要上游提供原生Range。

真实任务不存在、无法鉴权读取任务列表、视频服务不可达、非视频响应、编码不支持都会提示失败，不替换为假视频。切换离开专题卸载播放器，停止播放。

## 结果关联与边界

打开任务时同步读取LIVE路径结果，显示真实返回的匿名Global ID、综合分数、摄像头序列和时间，支持查看原始像素轨迹详情。视频中的检测标注由上游结果录像提供；尚未额外实现前端逐帧检测框叠加、双播放器同步或地图摄像头点击打开录像。原始像素点不会转换为GIS经纬度。

浏览器已实测两路metadata加载、首路实际播放时间推进，以及已核验任务的1个LIVE匿名对象关联。两路代理32字节范围请求实测均返回206、正确总长度及MP4文件头。
