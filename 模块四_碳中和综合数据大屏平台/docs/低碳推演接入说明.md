# 低碳推演专题

模块一计算保存，模块四后端自动读取，大屏只访问模块四。

读取链路：/api/sites 发现 HBUE → /api/scenarios 获取版本 → /api/simulation/long-term/runs 获取运行快照 → 筛选园区与冻结基准 campus_id/site_id → 匹配同一基准校验码 → 绑定原运行及 source_run_id 对应强化运行。

不写死数据库主键、年份或排放值。默认30秒刷新，后端缓存25秒；“刷新结果”强制读取。缺少结果时显示中文空状态，不自动创建运行、不借用其他园区结果。

## 初始场景

通过模块一公共API新增两份场景、两次基准小时运行及三份长期运行，未改模块一源码、未覆盖已有记录。scripts/prepare_campus_simulations.py --execute 是明确的新增记录操作，正常大屏读取不调用该脚本。

2024—2060，统一16栋建筑基准；负荷年增长1%，因子年下降1.5%，配额假设10000吨且年下降1%，电价假设0.57元/kWh且年增长2%，碳价85元/吨，中和阈值1吨。

低碳路径：2026空调和照明改造，2027新增光伏1200kW，2028储能400kWh，2030绿电35%。强化情景在此基础上增加光伏每年100kW、2034储能600kWh、进一步节能、绿电95%、年度抵消2500吨及因子年下降2.5%。均为示范参数，非学校部署事实。
