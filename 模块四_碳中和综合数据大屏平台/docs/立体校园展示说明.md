# 立体校园展示

模块四地图工具栏可切换“GIS地图 / 2.5D立体校园”。采用轻量SVG斜投影，不增加三维引擎依赖，不持续执行动画循环。保留二维地图，切回后恢复尺寸及热力渲染。

统一通过模块四现有空间接口读取真实校园边界、125栋建筑轮廓和校园道路中心线。经纬度先按校园中心转换为局部米坐标，再统一斜投影；建筑、道路、摄像头及轨迹使用同一坐标转换。原GeoJSON和16栋业务绑定不做任何修改。

建筑高度采用展示假设：业务建筑42显示单位、其他轮廓22显示单位，不代表真实测绘高度。核心楼栋增加轻量窗带，标签放大并按投影位置避让；校园采用较陡斜俯视，减少扁平横向取景带来的留白。立面为简化示意；道路中心线是真实数据，展示宽度为示意。该场景不是精确BIM复原，也不是独立真实设备系统。

16栋已绑定建筑显示悬浮名称、热力屋顶、建筑业务详情。未绑定轮廓只作空间背景，不分配能耗或碳排。碳排/能耗切换直接读取模块一原建筑结果；颜色按当前指标最大值归一化分5档，热点采用相同75百分位阈值，不重新计算业务结果。

校园边界、建筑轮廓、能碳热力、高值热点、跨镜路径开关同时作用于二维及立体视图。立体视图支持缩放、拖拽和复位。点击建筑打开同一详情面板；点击路径展示匿名ID、摄像头序列、起止时间及匹配分数。

DEMO与LIVE均使用同一ActivityPath数据结构，路径只使用摄像头空间节点或适配层明确输出的segments，视频像素坐标不参与投影。LIVE仍保留示范位置/假设时间的来源说明。示范分组取消仅移除相应路径；图层关闭隐藏全部路径，重新开启保留现有筛选结果。

验收边界：已实现2.5D场景加载、建筑能碳指标和跨镜活动路径同屏叠加；不宣称完整精细3D实景、真实摄像头部署或真实GPS连续轨迹。OSM来源及ODbL授权继续保留在二维底图与原空间数据元信息中。
