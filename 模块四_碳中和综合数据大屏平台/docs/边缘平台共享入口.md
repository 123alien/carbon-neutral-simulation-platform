# 边缘平台共享管理员入口

本入口经用户明确确认启用：大屏无登录，任何能访问入口的客户端均使用同一个边缘平台管理员身份，包括配置权限。它不是厂家单点登录，不提供用户隔离与逐人审计。仅用于受信任局域网，不能映射到公网。HTTP 本身不提供传输加密。

## 配置与启动

凭证通过后端环境变量 `EDGE_BOX_BASE_URL`、`EDGE_BOX_USERNAME`、`EDGE_BOX_PASSWORD` 配置，不写入代码、前端、网址或日志。Windows 当前部署使用用户级环境变量。

显式设置 `EDGE_SHARED_ADMIN_ACCESS=true`、`EDGE_GATEWAY_PORT=8210` 后，执行 `scripts/start_edge_gateway.ps1`，并重新启动大屏 BFF 使环境变量生效。入口 `/api/edge-entry` 会依据访问大屏的主机名跳转到同一主机的 8210 端口。跨电脑访问需允许该端口的入站流量；停用时将开关设为 false 并重启两个后端进程。

## 工作方式与边界

- 8210 与 5180 是不同浏览器源，边缘平台前端不能直接访问大屏存储。代理固定转发至已配置的边缘平台，拒绝外部目标和跳转。
- 原平台页面与接口经过代理；Digest 密钥计算与过期重登录留在后端。浏览器中的会话占位符不是设备密码，不能用于登录设备原地址。
- 当前前端适配针对已核验的厂商版本，若厂商修改关键认证函数/路由守卫，适配返回错误而不偷偷下发密码。
- 转发 WebSocket，供平台原有实时事件和视频连接使用；具体算法推理、摄像头在线与视频可用性仍由原平台决定。
- 上游管理接口的业务功能与权限沿用共享账号；代理不等同于只读接口。操作设备配置须由使用者自行确认。
- 原平台部分设置/数据返回本身可能包含摄像头凭证，这属于管理员可访问的原业务数据，不应向不受信任用户开放。
- 共享入口不能代替真实摄像头联网，不会将离线点位伪装为在线。
