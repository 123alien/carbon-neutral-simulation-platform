# 跨镜平台一键进入

大屏入口 `/api/cross-entry` 跳转到访问大屏的同一主机之 8220 端口，保留任务编号。代理固定连接 `CROSS_CAMERA_BASE_URL`；当前通过 `http://10.120.203.134:5174` 访问跨镜后台接口，原直连 8100 端口从大屏主机不可达。

后端变量 `CROSS_CAMERA_USERNAME`、`CROSS_CAMERA_PASSWORD` 保存登录凭证，Bearer Token 缓存与过期重登也在后端。浏览器仅保存 UI 占位符，登录状态通过认证代理的 `/api/v1/auth/me` 恢复，无需再次输入密码。

用 `CROSS_SHARED_ADMIN_ACCESS=true` 显式启用后，执行 `scripts/start_cross_gateway.ps1`，并重启大屏 BFF 使入口配置生效。停用时把开关设为 false 并重启两个服务。后台 API 与媒体请求转发到固定跨镜上游；任务计算、视频与识别结果仍属于跨镜系统，不在 BFF 重算。

这是共享账号入口，不是厂商单点登录或逐人权限系统。可达用户共享该账号的权限，只应在受信任局域网中使用，不应公开到互联网；HTTP 不提供传输加密。原跨镜系统运行在开发服务器，其开发热更新连接不属于业务接口。
