# 当前天气联动

三维天气默认选择“当前区域天气”，通过模块四后端 `/api/weather/current` 读取Open-Meteo当前天气，前端不直接请求外部服务。请求坐标为校园参考中心WGS84：114.42966、30.42023。上游返回气象模型网格坐标，接口同时保留请求坐标与网格坐标，不能将模型格点描述为校园气象站。

2026-09-17联调：接口成功返回小雨、温度22°C、湿度94%、风速6.9km/h、降水0.1mm，气象时间17:45+08:00。此值是外部区域天气模型输出，不是随机示范数据，也不是学校设备实测。校园原气象站离线且有效指标数量为0，本次没有伪造其恢复在线，也没有替换校园能源核算数据。

前端每5分钟刷新，页面不可见时暂停刷新。后端缓存5分钟并合并并发请求，失败缓存30秒。保留上游气象时间和接收时间，不把请求时间当作气象更新时间；拒绝超过2小时或明显未来的数据。显示温度、湿度、风速、降水时保留上游真实单位，不补缺失值。

WMO天气代码用于映射晴/阴/雨氛围；真实天气名称保留雾、雪、雷雨等差异。当前雪只使用阴天氛围，不伪装已支持积雪模型。昼夜按上游is_day联动；光照与雾效属于展示表达，非实测光照仿真。天气接口失败显示暂无有效天气，采用中性背景，不自动切换为示意天气。

手动“示意天气”仍作为显式独立选项保留，带有非实时说明。风格展示不改变负荷、光伏、储能或碳排结果；需要把真实天气用于计算时应另行纳入模型参数和运行记录。

下雨时显示独立Canvas动态雨幕：最多150个屏幕空间雨滴，绘制上限30帧/秒，雨滴密度随上游降水值作展示性调整，不声称物理雨量还原。动画不驱动WebGL场景持续重绘。页面隐藏、专题隐藏、组件卸载时停止动画；系统开启减少动态效果时使用静态雨幕。晴天、未知天气不保留雨层。

数据来源：https://open-meteo.com/；字段与代码参考：https://open-meteo.com/en/docs。正式商业部署前应按其当期服务条款确认适用的订阅及授权。
