# 阶段二：校园结果与跨镜结果接入

已接通模块一 HBUE 校园动态示范结果：16栋建筑、六项指标、24小时能源趋势、月度碳排、建筑排名、碳排/用电热力、上四分位热点、建筑详情与直接/间接排放分项。

热点按16栋已绑定建筑当前累计指标计算75%分位阈值，不用于宣称学校真实高耗/高碳异常。未绑定轮廓无业务值。

跨镜页面通过模块四后端读取已有模块一适配服务：25个匿名对象，5类活动，多选增减、匿名编号、摄像头和匹配分数过滤，路径详情保留像素轨迹。示范数据不会自动切换冒充真实；本次仅验证示范链路，未验证局域网LIVE认证链路。

实际检查：HBUE校园尚无已完成年度情景/长期路径，保持空状态，不生成新的计算任务；长期接口读取能力已经建立。碳市场独立统计能读取上游现有市场序列，不代表学校真实交易。原路径/强化情景按上游 annual 年度结果展示，不伪造置信区间。

物联网状态：读取既有外部采集状态；服务连接与设备在线/有效值分开显示。当前不触发上游新采集。凭证仍留在模块一已有后端，本模块四前端不接触凭证。

当前未实现：三维加载与轨迹叠加、自定义指标引擎、独立物联网鉴权采集、持久化配置、流式高并发、完整模块四验收。模块一未改动。

## 验证命令

模块根目录执行 python -m pytest tests -q；frontend 下执行 npm run build 和 npm run e2e。

浏览器测试使用本机 Edge，不依赖额外 Chromium 下载。后端需运行在8200、模块一在8000、前端在5180。

本次最终回归：后端10项通过；浏览器2条核心流程通过（校园指标、图层、专题；25条轨迹加载、分组增减、匿名编号过滤）；前端类型检查及生产构建通过。npm依赖审计0项漏洞。构建保留图表分包大于500KB提示，非失败项；尚未做高并发及完整性能验收。
