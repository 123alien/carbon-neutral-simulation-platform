# 第一阶段：独立骨架

模块一源码、数据库及空间文件均不写入。开发阶段只读其现有校园 GeoJSON，独立部署时通过 HBUE_SPATIAL_DIR 指向空间文件目录。

## 启动

在本模块根目录打开终端：

```powershell
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8200
```

另开终端进入 frontend：

```powershell
npm install
npm run dev
```

浏览器访问 http://127.0.0.1:5180 。前端只请求本平台 /api，开发代理转发到 8200。生产部署需配置同源反向代理。
