# 大屏布局修正

问题来自侧栏 flex 压缩与图表160px最小高度冲突，图表和canvas超出卡片；图例采用默认位置，与横轴重叠。

修正：综合/空间专题使用视口高度、主区弹性剩余空间；侧栏明确网格行高，卡片和图表 min-height:0；图例移至顶部并支持滚动。低高度窗口紧凑排版；窄屏允许页面纵向滚动而非裁剪。低碳推演和配置页保留纵向文档布局。

GIS原有颜色、轮廓、业务数据和接口不变；热力图例避开缩放按钮。

碳价曲线仅显示上游有效碳价记录，忽略只包含其他市场指标的空碳价行，不插值、不补造数据、不改变上游计算。

新增自动化检查1227×900、1366×768、1920×1080下视口溢出、图表/卡片边界、canvas尺寸及相邻卡片重叠；窗口缩放及专题返回后检查重新适配。核心业务与布局合计7条浏览器流程通过；类型检查/生产构建通过，保留既有图表分包大小提示。
